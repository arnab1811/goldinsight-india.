# GoldInsight India v3
Upload index.html to GitHub Pages (main branch, root). No API keys or dependencies. Opening the page or clicking Refresh rates attempts three public HTTPS feeds: Snapdata Indian 22K daily benchmark (IBJA attribution), Frankfurter v1 EUR reference rates, and Gold API USD spot. Failed requests preserve existing calculator inputs; available prior observations are cached locally and marked as saved. Manual baselines remain editable; explicit refresh may replace them. Daily data are not real-time tradeable quotations. The spot-derived 22K equivalent is separate from the local benchmark. The scenario chart is illustrative, not a forecast. Sources and formulas appear in the page. Browser connectivity and provider availability are required for updates. JavaScript syntax checked; live browser requests not tested in the restricted build environment.
